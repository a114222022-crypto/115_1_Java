# 第五週 AI 使用紀錄

另存 AI_USAGE.md。每欄簡短填寫，不貼完整對話。使用真實服務、教師示範、模擬建議要據實標示。未使用 AI，第一欄寫「未使用」及原因，其餘可填不適用；本人課堂測試仍填 LAB_REPORT。不要上傳個資、密碼、憑證或未授權程式。

| 欄位 | 本人紀錄（陳奕璇） |
|---|---|
| 使用工具／方式 | 真實 AI（Gemini） |
| 目的與提問摘要 | 詢問 `MissionStep` 類別封裝（`this` 指派、getter、字串內容比較）與 `MissionLog` 歷程紀錄走訪、摘要統計的實作方式 |
| 建議與本人處理 | 採納以 `"OK".equals(this.result)` 取代 `==` 避免參考位址比較與空指標風險，並於每次迴圈結束時 `new MissionStep(...)` 存入 `history`；自行核對第四週 `printReplay` 輸出格式後微調字串拼接 |
| 本人實際驗證 | 本地編譯執行 `MissionLog` 測試預設腳本 `{1, 1, 2}`（初始 energy=20, samples=0），確認逐步回放正確記錄能源變化（14、8、6），統計結果為 `steps=3, ok=3, rejected=0, ignored=0`、`lowest energy=6`、最終 `6/5/3 SUCCESS` |
